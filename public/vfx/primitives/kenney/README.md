# Kenney Particle Pack primitives

Selected files from Kenney's Particle Pack, distributed under CC0 1.0 Universal.

Original project page: https://kenney.nl/assets/particle-pack

Repository mirror used for byte-for-byte import:
https://github.com/Calinou/kenney-particle-pack

Imported originals:

- `slash_03.png`
- `spark_04.png`
- `magic_03.png`
- `smoke_05.png`

No image modifications were applied during import. Runtime scale, opacity and
composition are controlled by Arkamon's VFX manifest/recipe engine.

See `LICENSE.txt` in this directory and `docs/VFX_ASSET_STRATEGY.md` for full
provenance.
