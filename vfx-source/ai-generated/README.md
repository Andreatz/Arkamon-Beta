# Originali VFX generati e provenienza

Questa cartella contiene **306 PNG originali immutati**: 276 versioni selezionate e 30 precedenti rigenerazioni conservate come provenienza. Gli originali non sono pubblicati nel bundle del gioco.

`provenance/generation-manifest.json` lega ciascun ID moveset al PNG runtime e all’originale selezionato, con SHA-256, QA, prompt e note. I percorsi sono relativi alla radice del repository; `generation_source_filename` conserva il nome del file restituito dal generatore. Le precedenti versioni e i loro tempi di registrazione restano nell’elenco `originals`.

Modalità documentata: built-in image_gen. 170 record hanno prompt effettivo e strumento registrati individualmente; i 106 record storici non sono stati completati per deduzione. I [prompt editoriali](../../docs/vfx-generated-moves/prompts/Prompt_VFX_276_mosse_Arkamon.md) e la [documentazione finale](../../docs/vfx-generated-moves/README.md) spiegano i limiti della revisione.
