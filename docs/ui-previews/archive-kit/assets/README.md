# Risorse dell’anteprima Arkamon

`vector/` contiene i 47 SVG esatti dell’archivio fornito. Il catalogo JSON aggiorna metadati, dimensioni reali e SHA-256, documentando l’origine di ogni risorsa. Gli SVG non sono ricolorati, rigenerati o modificati.

`previous-vector/` contiene i precedenti SVG viola, utilizzati soltanto per il confronto nel catalogo.

`art/`, `creatures/`, `original-ui/` e `fonts/` conservano copie dei materiali originali del gioco. `fixtures.json` fornisce dati dimostrativi. `icons/` e `items/` contengono gli elementi di supporto usati dalle anteprime per gli stati e per gli oggetti che non hanno equivalenti nel kit fornito.
