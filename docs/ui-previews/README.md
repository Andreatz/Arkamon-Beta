# Anteprime grafiche Arkamon

La [consegna corrente con gli SVG forniti](archive-kit/README.md) contiene le sette anteprime interattive, i 47 asset dell’archivio dell’utente, il confronto con i 47 SVG precedenti, le immagini desktop/telefono e le verifiche.

Le anteprime usano dati dimostrativi. La loro pubblicazione conserva il kit e la proposta grafica per la successiva integrazione nell’interfaccia del gioco.

Per aprire il catalogo e tutte le schermate, avviare `python -m http.server 3010 --bind 127.0.0.1` dalla radice del repository e visitare `http://127.0.0.1:3010/docs/ui-previews/archive-kit/#overview`.

Gli SVG del kit corrente sono copie identiche dei file in `Arkamon-Assets-SVG.rar`; le impronte sono documentate in `archive-kit/quality/archive-import.json`. La documentazione e i collegamenti della copia nel repository sono adattati per funzionare anche dopo un clone.
